# Roadmap

Future ideas, in rough priority order. None of these are built yet.

## Next
* Record narration for all story scenes, prayers and verses (ElevenLabs, natural voices only).
* Finish the illustrations: mascots, portraits, lesson covers, story scenes, badges.
* Write the 32 planned lessons in `data/curriculum-plan.ts` (path to 60), then grow to 150+.
* Record the original songs; add timing data for word-by-word highlighting.
* Browser-based lesson editor in the admin area (drafts stored in the database, published to files).

## Later
* Spanish-language mode and other languages (content keyed by locale).
* Original animated Bible videos and an audio story library.
* Church, Sunday School and homeschool accounts with teacher lesson plans and printable packs (an optional paid supplement for organisations, never for core child features).
* Family learning challenges and parent-approved lesson scheduling.
* Seasonal adventures (Christmas, Easter journeys).
* Offline downloads / PWA, then a native mobile app.
* Advanced Bible geography and history modules for Faith Champions.
* Optional denominational settings (for example, how baptism and communion are described).
* Additional licensed Bible translations (the data model already stores a translation per passage).
